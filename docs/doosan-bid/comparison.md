## 발견 사항
1. **2kg batch가 4kg보다 제조원가가 낮음(△52원/g)** — 일반적으로 batch가 클수록 고정비가 낮아야 하므로 직관과 반대. 설비 규모·가동률 가정 확인 필요.
2. **2032·2033년 수식 오류 의심** — 2027~2031은 매년 +0.7억 차이가 일정한데 2032는 +0.1, 2033은 0.0. 두 시트 중 한쪽의 2032~2033 셀이 값으로 붙여넣어졌거나 다른 원가를 참조하고 있을 가능성. 정상이면 #2 소계는 약 △137.3억.
3. 부가가치·매출은 두 시트 완전 동일 → 부가가치는 고정비·변동비 차이에 영향받지 않는 정의(예: 매출−재료비−외주 등)로 보임.
4. 판가 셀(7,657 vs 7,818)은 다르지만 매출은 동일 → 판가 셀이 매출 수식에 연결되어 있지 않을 수 있음.
